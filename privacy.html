Política de privacidad

Última actualización: 19 de noviembre de 2026.

GTA Clips es una herramienta personal que sube vídeos al canal de YouTube de su propietario mediante la API de YouTube. Solo la usa su autor.

Datos a los que accede

La aplicación se autoriza con OAuth 2.0 únicamente con la cuenta del propietario del canal y el permiso de subida de vídeos de YouTube. Solo sube vídeos y miniaturas a ese canal. No lee, no recoge y no almacena datos personales de ningún otro usuario.

Para localizar clips usa la API pública de Twitch con credenciales de aplicación; no accede a cuentas ni a datos privados de usuarios de Twitch. Del clip solo se leen datos públicos: título, número de vistas, duración y nombre y enlace del canal del streamer.

Datos que se guardan

  • Las credenciales OAuth del propietario y de la aplicación de Twitch se guardan como secretos cifrados de GitHub Actions y no se publican.
  • Un historial de clips ya usados (identificadores públicos de clip) para no repetirlos.

Compartición de datos

No se venden, comparten ni transfieren datos a terceros, ni se usan para publicidad.

YouTube y Google

La aplicación usa los servicios de la API de YouTube, por lo que se aplican los Términos del servicio de YouTube y la Política de privacidad de Google. El propietario puede revocar el acceso en cualquier momento desde security.google.com/settings/security/permissions.
